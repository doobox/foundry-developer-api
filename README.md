# Foundry Developer documentation

The documentation is a GitHub Pages site built with Jekyll.

## Preview locally

Install Ruby 3 and Bundler, then run:

```sh
cd docs
bundle install
bundle exec jekyll serve
```

Open <http://127.0.0.1:4000/foundry-developer-api/>. Jekyll watches the source files and rebuilds the site as they change.

The `github-pages` gem keeps the local dependency set aligned with GitHub Pages.
