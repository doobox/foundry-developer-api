<p class="eyebrow">Framework interchange</p>
<h1>Frameworks in packs</h1>
<p class="lede">Foundry imports and exports reusable framework settings inside the <code>Frameworks</code> directory of a normal Foundry pack.</p>
<p>New frameworks start from the bundled System UI defaults and require a title and supplied image. Frameworks in installed release packs and built-in frameworks are read-only. Frameworks in development packs remain editable. Update Framework saves edited settings into the reusable framework; Edit Framework changes only its title and artwork.</p>
<p>Saved frameworks include only the fixed framework colour palettes: Page, Surface, Text, Muted, Brand, Accent and Links. Custom colour palettes belong to the project and are not included. Standard colour palettes are supplied by Foundry and are not bundled.</p>

<h2>Directory structure</h2>
<div markdown="1">

```text
Example.foundrypack/
├── Info.plist
└── Frameworks/
    └── Brand/
        ├── Info.plist
        └── Resources/
            ├── framework.json
            ├── preview.png
            └── Assets/
                └── <managed font files>
```

</div>
<p>The framework item directory has no filename extension. Its current internal format is version <code>5</code>. Foundry's framework export action creates the complete outer <code>.foundrypack</code> shown above.</p>

<h2>Framework Info.plist metadata</h2>
<dl>
<dt>id</dt><dd>Required stable UUID.</dd>
<dt>name</dt><dd>Required non-empty display name.</dd>
<dt>previewFilename</dt><dd>Required filename below the framework item's <code>Resources</code> directory.</dd>
<dt>formatVersion</dt><dd>Required integer. The current supported value is <code>5</code>.</dd>
<dt>createdAt / modifiedAt</dt><dd>Required plist dates.</dd>
<dt>resources</dt><dd>Required array describing bundled project assets and their storage filenames; normally generated by Foundry.</dd>
</dl>

<h2>Preview image</h2>
<p>A valid PNG, JPEG or WebP preview is required, with an extension matching its contents. Tiles use a <code>2:1</code> aspect ratio; <code>1200 × 600</code> pixels is recommended. Other dimensions are accepted and cropped to fill the tile.</p>

<h2>framework.json</h2>
<p>The JSON payload stores colour palettes, spacing, typography, screens, shadows, border widths and border radii. Breakpoints remain project settings: applying a framework preserves the project's enabled breakpoints, minimum widths and container-width rules.</p>
<div class="callout warning"><strong>Use Foundry to author framework items.</strong> <code>framework.json</code> is a Codable interchange payload rather than a separately versioned third-party authoring API. Export a framework from Foundry to obtain canonical metadata, resource records and font storage names before editing or distributing it.</div>

<h2>Part integration</h2>
<p>Parts do not read <code>framework.json</code> directly. Declare <a href="framework-controls.html">framework-aware controls</a>; Foundry resolves their semantic selections against the active project framework before substituting template values.</p>
