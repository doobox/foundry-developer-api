<h1>Control groups</h1>
<p class="lede">Add a coordinated set of Inspector controls maintained by Foundry. Each group has its own generated control IDs, defaults and template contract.</p>

## Declare a control group

Place a group dictionary inline in the `controls` array, at the position its Inspector section should occupy. Unlike a custom control, a group needs only its `type` and does not take an `id`, `label` or `group`.

```json
"controls" : [
    {
        "type" : "spacing"
    }
]
```

The generated controls participate in responsive values, template access, validation and Inspector grouping like controls declared directly by the part. The section uses Foundry's standard name and icon automatically. A part may declare each group type at most once, and custom control IDs must not duplicate the IDs generated by a declared group.

Most groups supply values but do not style or script the part. Use their `control.…` values in your templates. [Background](background-control-group.html) additionally requires a `{{ controlGroup.background }}` placement macro and generates the corresponding CSS and conditional video markup. [Reveal](reveal-control-group.html) generates its GSAP animation and automatically requests GSAP with ScrollTrigger.

## Override generated defaults

Spacing, Sizing, Borders, Effects, Reveal and Layout item accept `defaultOverrides`. Its keys are generated control IDs from that group's reference page. Each value replaces the complete base default for that control; it does not merge with the original value.

```json
{
    "type" : "spacing",
    "defaultOverrides" : {
        "frameworkPadding" : {
            "top" : "sm",
            "right" : "md",
            "bottom" : "sm",
            "left" : "md"
        }
    }
}
```

<h3 class="property-heading"><code>type</code></h3>
<div class="property-meta"><span class="property-type">String</span><span class="required">Required</span></div>

One of `background`, `spacing`, `sizing`, `borders`, `effects`, `reveal`, or `layoutItem`.

<h3 class="property-heading"><code>defaultOverrides</code></h3>
<div class="property-meta"><span class="property-type">Dictionary</span><span class="optional">Optional</span><span class="default">Default: generated defaults</span></div>

Replaces selected generated base defaults. Available for `spacing`, `sizing`, `borders`, `effects`, `reveal`, and `layoutItem`; Background defines its configuration through `styles` and `states` instead. Use only IDs and complete values documented by the selected group's page.
